# mfmap

mfmap is a fork of [Eclipse COBOL Language Support](https://github.com/eclipse-che4z/che-che4z-lsp-for-cobol) (Che4z), a COBOL language server, repurposed to generate abstract syntax trees from legacy COBOL applications for modernization. It carries the original project's license, the Eclipse Public License 2.0 ([LICENSE.md](LICENSE.md), [NOTICE.md](NOTICE.md)).
